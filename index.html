Cotizaciones archivadas automáticamente

Cuando el historial activo de cotizaciones queda demasiado pesado para guardarse, el sistema archiva solo las más antiguas para que el resto del equipo pueda seguir guardando. No se borran: quedan acá para descargar.

Mismo mecanismo que arriba, pero para el historial de "último precio cotizado a cada cliente" (el que usa el comparador para avisar si le cotizaste distinto antes).

Exportar / importar historial completo

Para no perder nada si algún día hay que republicar la app: descargá este archivo antes, y subilo en la versión nueva. Incluye datos sensibles (usuarios y claves), por eso es solo para admin.

Precios de competencia

Bulk (Producto en col. A, un competidor por columna) — para reportes tipo Bionexo. Relaciona automáticamente cada producto con tus monodrogas por nombre + dosis. Si al lado de la columna de precio de un competidor hay otra columna sin encabezado, la toma como la marca de ese competidor.

Plazo de pago a laboratorios/proveedores

Directo por laboratorio (sin depender de ningún convenio de cliente). Se muestra en el Comparador, debajo del nombre de cada producto, cuando ese laboratorio matchea con la planilla.
Mapeo de laboratorios

Vinculá cada laboratorio de tu Base de marcas con su razón social en la planilla de proveedores (esto se hace una sola vez; si agregás un laboratorio nuevo, aparece acá para mapearlo).

Precios por lista de precios (para comparar en el Comparador)

Carga el costo de cada producto en varias listas a la vez (IAPOS, OSDE, CCESPECIAL, CLINIC/SAN, etc.), para poder elegir en el Comparador contra cuáles comparar.
Subir archivo (Codigo / Lista / Monodroga / Laboratorio / Marca / Costo / PVP / PSL / Descuento)

De una sola carga actualiza el catálogo completo de la Base de marcas (usando la lista CLINIC/SAN) y llena la comparación entre todas las listas.

Stock por lista de precios (para comparar en el Comparador)

Carga el stock de cada producto en cada lista/depósito a la vez, para ver en el Comparador cuánto hay disponible según la lista que elijas.
Subir archivo (Codigo / Lista / Monodroga / Marca / Stock)

De una sola carga actualiza el stock de la Base de marcas (sumando OSDE + CCESPECIAL + CLÍNICA/SANA) y llena el stock por lista para todos los depósitos. Registra los movimientos como siempre.

Importar catálogo propio (archivo completo)

Carga o actualiza directamente la Base de marcas desde un CSV con columnas Codigo / Monodroga / Laboratorio / Marca / Costo / PVP / Vencimiento / Stock / Unidades por caja / Proteger Costo. Busca primero por Código; si no hay coincidencia, por Monodroga+Laboratorio+Marca. Actualiza lo existente y da de alta lo nuevo — no borra lo que no venga en el archivo.
